# 8Bit Simulator — yükləmələr

Bu repo yalnız **8Bit Simulator** proqramının quraşdırıcı fayllarını və avtomatik
yeniləmə məlumatını (`latest.json`) saxlayır. Proqramın mənbə kodu burada deyil.

## Yükləmə

Son versiyanı **[Releases](https://github.com/Shikhiyev/8Bit-releases/releases/latest)**
bölməsindən yükləyin (`...-setup.exe` faylı).

Proqram quraşdırıldıqdan sonra yeni versiyalar avtomatik təklif olunur —
yenidən yükləmək lazım deyil.

---

Rəsmi sayt: [8bit.az](https://8bit.az)

## Proqramı uzaqdan bağlamaq (yalnız sahib üçün)

`status.json` faylında `"enabled": false` yazılsa, bütün istifadəçilərdə proqram
bağlı ekrana keçir (açılanda və açıq ikən 10 dəqiqədən bir yoxlanılır).
`"title"` və `"message"` sahələrində istifadəçilərə göstəriləcək mətni yaza bilərsiniz.
Yenidən açmaq üçün `"enabled": true` edin.
